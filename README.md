# Consultas SQL sobre Base de Datos Bancaria

Este repositorio contiene material didáctico para el aprendizaje de SQL utilizando una base de datos de ejemplo de un banco. El material está diseñado para estudiantes de Ingeniería Informática en la asignatura de Bases de Datos.

## Contenido

### Temas Cubiertos

1. Consultas básicas
   - Selección de datos
   - Filtrado con WHERE
   - Eliminación de duplicados

2. Operadores SQL
   - AND, OR, IN
   - BETWEEN
   - LIKE
   - Operadores de comparación

3. Joins y combinación de tablas
   - INNER JOIN
   - LEFT JOIN
   - CROSS JOIN
   - Productos cartesianos

4. Funciones de agregación
   - COUNT, SUM, AVG
   - MIN, MAX
   - GROUP BY
   - HAVING

5. Subconsultas
   - En la cláusula WHERE
   - En la cláusula FROM
   - En la cláusula SELECT

6. Vistas
   - Creación de vistas
   - Ejemplos prácticos
   - Consultas sobre vistas

## Estructura de la Base de Datos

La base de datos contiene las siguientes tablas principales:
- Clientes
- Cuentas
- Empleados
- Sucursales
- CtaCli (relación entre clientes y cuentas)

## Uso del Material

1. Revisar el documento principal `index.adoc` para la explicación teórica
2. Consultar `queries.sql` para ver ejemplos prácticos de consultas
3. Practicar las consultas en un gestor de bases de datos SQLite o similar

## Requisitos

- Sistema de gestión de bases de datos SQLite, MySQL o similar
- Conocimientos básicos de SQL
- Editor de texto o IDE con soporte para SQL
